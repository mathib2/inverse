## Pint unit conversion and dimensional analysis
Pint represents physical quantities with magnitudes, units and dimensionality. Its UnitRegistry holds unit relationships and a quantity's to method converts to a compatible unit. A conversion from 1000 millimetres to metres gives 1 metre. Converting a length to a mass should fail rather than inventing a conversion factor. Keep the original input unit and normalized value in calculation evidence. Dimensional compatibility is necessary but not sufficient for physical correctness: torque and energy have matching base dimensions but different meanings. This feature includes explanatory notes, not an executable Pint tool. A future conversion interface should accept a numeric magnitude and separately validated unit identifiers, use a restricted registry, reject non-finite numbers and return the installed library version alongside the result. Do not execute text copied from a reference.

## Absolute temperature and temperature differences
Offset scales require distinguishing an absolute temperature from a temperature interval. An absolute 20 degrees Celsius corresponds to 293.15 kelvin; an increase of 20 Celsius degrees corresponds to an increase of 20 kelvin. Applying the offset to a temperature difference produces an incorrect heat calculation. Define the operation and quantity kind explicitly before conversion. Multiplying an absolute offset temperature into an arbitrary formula is not the same operation as using a temperature difference. For Q = m*c_p*delta_T, delta_T is an interval. Keep the start and end temperatures, scale and subtraction step in evidence. The retrieval system does not perform this conversion and must not label a result dimensionally validated. A future typed adapter needs separate cases and regression fixtures for absolute and differential temperatures.

## Pressure, angles and unit identity
One megapascal equals one million pascals; displaying 10 Pa as 10 MPa is a millionfold error even though the number token is unchanged. Degrees and radians must also be distinguished before calling a trigonometric function. Preserve a quantity's semantic name along with its units so pressure cannot be confused with stress solely because both use pascals. Gauge and absolute pressure need reference information, not just a scale conversion. Unit labels in generated prose are not validation evidence. The current numeric verifier compares magnitudes and cannot establish these relationships. Use this limitation as a regression case and retain an explicit unchecked notice when references accompany calculations. A future Pint adapter can check dimensions and conversions, while a separate engineering rule must still check the selected physical meaning and applicability.

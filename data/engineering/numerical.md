## SciPy bracketed root finding
SciPy offers numerical optimization and root-finding tools. A bracketed scalar root problem needs a continuous function on a finite interval and endpoint values with opposite signs, unless an endpoint is already a root. For f(x) = x^2 - 2 on [1, 2], the positive root is approximately 1.4142135623730951. Check the final residual and the solver's convergence indication, not just its returned number. A sign change does not by itself prove continuity. Distinguish tolerances on the variable from tolerances on the function residual. This is guidance for a future named operation; no arbitrary callable, Python expression or SciPy solver is exposed by the search tool. A later adapter should bound evaluations and iterations and return the method, bracket, tolerances, residual and installed library version.

## Numerical parameter identification
Least-squares fitting compares model predictions with observations using defined residuals. Identify which parameters are free, which are known and which bounds are physically justified. For oscillator recovery, a fitted decay rate and damped frequency determine c/m and k/m; a known mass is needed to determine unique c and k. Normalizing residuals by sensor uncertainty can prevent a noisy channel from dominating the objective. A small residual alone does not demonstrate parameter identifiability or uniqueness. Preserve the input dataset, units, fitting interval, objective definition and solver termination reason. Validate on withheld observations or another independent physical check. INVERSE currently generates synthetic oscillator data but this reference feature does not add a fitting tool. Do not report hidden fixture parameters as recovered estimates.

## Integration and numerical error
Numerical integration approximates a defined mathematical problem. State the integrand or differential equation, interval, initial conditions and error controls. For the ordinary integral of x from 0 to 2, the exact value is 2; this simple case is useful as a regression fixture. Adaptive methods estimate numerical error under their assumptions, not model error or uncertain measurement input. Discontinuities, singularities and stiff dynamics require special care. A differential-equation solution should be compared with a known analytical case when one exists. Record tolerances and reject non-finite output. The existing synthetic generator uses a closed-form linear solution and fixed-step Runge-Kutta for other cases; this does not make the agent crew a general integrator. Future SciPy execution belongs behind an explicit bounded interface, separate from document ingestion.

## Numerical precision and conditioning
An exact formula can still be poorly conditioned or evaluated inaccurately. Avoid subtracting nearly equal large values when an equivalent stable expression exists. Keep sufficient internal precision and round only the displayed result according to an explicit rule. A small change in input that creates a large output change should be reported as sensitivity, not hidden by extra decimal places. Validate finite inputs and outputs and distinguish absolute from relative tolerances near zero. A deterministic calculator checks its selected expression; it cannot confirm that the expression represents the intended engineering quantity. Benchmark expected outputs by named quantity and unit instead of searching for matching number tokens anywhere in an answer. Reference retrieval adds explanatory context but does not repair the existing verifier's sign, unit or quantity-binding limitations.

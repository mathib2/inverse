# Synthetic data (no real plant data)

The data platform federates one synthetic service, `services/obs-service`, generated by `core/inverse_core/datasets.py` with fixed
seeds (numpy only): deterministic, reproducible, and small.

- **Registry** (`/equipment`): two machines, `P-104` (a process pump mount, baseline and current datasets) and `T-200` (a test rig,
  current dataset only, no baseline).
- **Sensor specifications** (`/sensors`): displacement and velocity sensors with their units, noise levels and sampling rates.
- **Samples** (`/datasets/<id>/samples`): a damped free-decay signal per dataset: `p104-baseline` (400 samples at 100 Hz),
  `p104-current` (same machine a month later, damping 40% higher), `trap-current` (200 noisy, weakly damped samples).
- **Maintenance history** (`/maintenance`): three notes; one (`M-002`) carries a planted instruction aimed at an AI, which the
  injection guard withholds before any model sees it (`tests/test_guard.py`).

Zetaris exposes these as `obs.equipment_table`, `obs.sensors_table`, `obs.maintenance_table` and `obs.*_samples`
(`data/zetaris/`, `scripts/admin/setup_zetaris.py`). The crew only ever reads them.

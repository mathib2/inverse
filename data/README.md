# Synthetic data (no real plant data)
All datasets are generated by `core/inverse_core/datasets.py` with fixed seeds and served by `services/obs-service`.
- **P-104 baseline**: m=1 kg, c=2.0 N·s/m, k=100 N/m, release from x0=1 m, sigma_x=0.01 m, 400 samples at 100 Hz.
- **P-104 current**: c=2.8 (+40%, wear), seed 2.
- **T-200 (trap)**: c=0.15, sigma_x=0.04 m, 200 samples, seed 68. Chosen by search so that a 4-parameter model fits better (chi2 181.4 vs 188.7, AIC 193.4 vs 196.7, both with the initial state fitted) but has negative damping (c = -0.28). How rare this is: with the same generator the full trap (lower chi2 AND lower AIC AND negative damping) occurs in 5 of 80 seeds, and across 30 seeds INVERSE accepted the wrong model 0 times.
- **Unidentifiable case**: the same free-decay data asked with the mass unknown (only c/m and k/m exist in the data).
- `/maintenance` contains one planted, harmless instruction string to test the injection guard.

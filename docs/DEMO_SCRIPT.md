# Demo script (3 minutes)

Everything below is the live crew page unless marked **replay**. Keep a saved mission with a good conversation ready under
**Past missions** in case the live model is slow.

| Time | On screen | Say |
|---|---|---|
| 0:00 | The crew page, the eight cards | "INVERSE is a crew of eight AI agents on one computer, on local models, no cloud. Atlas plans, Vera reviews, Warden keeps watch; Scout, Euler, Ada, Sentinel and Forge do the work." |
| 0:20 | Type a goal, press **Go** ("What do we know about P-104?") | "One box. Atlas plans the mission and the agents review the plan. Watch the plain sentences: who starts what, which tool they used, what Vera sent back and why." |
| 1:00 | The answer, **Who did what**, **What they said to each other** | "Every claim cites its evidence. What did not finish is listed by code, never paraphrased. And this is the conversation: results announced to everyone, Vera's notes, Ada asking Euler a question." |
| 1:40 | **On its own**: Warden awake, standing missions, the table of missions it started | "Nobody asked for these. Warden runs queued goals, standing missions on a schedule, and a mission for every machine whose sensor data changed. Each run has a manifest." |
| 2:10 | **Past missions**, **Show** a Warden mission (**replay**) | "Any mission replays from its files, no model needed, conversation included." |
| 2:35 | **Advanced**: the experts editor, Forge's created agent, the trace | "Agents are configuration. Forge can build one during a mission. Every model call, tool call and review is in the trace with the served model." |
| 2:55 | Back to the crew page | "Local, autonomous, checked. The sponsor paths: Zetaris is the only data path, H-MEM is the shared memory with a trust order, Markovian runs the long reviews, Nemotron runs every agent." |

Fallbacks: if the model is slow, go to **Past missions** at 0:40 instead of waiting. If Warden is asleep, the table still shows
what it did. If the data platform is offline, Sentinel's code review mission needs no data.
